Помощь проекту

This page is still being filled in. For now, use the sections below as the current contributor entry points for code, docs, and translation work.

If you are doing maintainer-style work with coding agents, start with AI-Assisted Development. It covers the shell setup, local server loop, and the skills in .skills/.

You can also use the guide in the GitHub repository wiki written by ReinforceZwei.

For now, the project has three main contribution paths:

  • code and bot work in the main MCC client
  • documentation updates in docs/
  • translations through Crowdin

Переводы

Чтобы улучшить переводы для MCC, перейдите на страницу: Crowdin — Minecraft Console Client.

Рекомендуем сначала переводить текст MCC в приложении.

If you cannot find the language you want to translate into, contact us on GitHub or Discord and we can add it.

GitHub: https://github.com/MCCTeam/Minecraft-Console-Client
