À propos

Minecraft Console Client (MCC) is a lightweight, cross-platform, open-source Minecraft TUI client for Java Edition. It lets you connect to Minecraft Java servers, send commands, and receive text messages without launching the main game.

It also includes built-in automation for administration and utility work, plus an extensible C# API for creating bots and runtime scripts.

Ce projet prend sa source d'un projet de ORelio de 2012 sur Minecraft Forum, maintenant il est maintenu par lui, mais aussi par de nombreux membres de la communauté.

Features

  • Chat

    • Envoyer et recevoir des messages dans le chat
    • Enregistrer l'historique du chat
    • Recevoir des alertes en fonction de mots-clés
    • Réponses automatiques

  • Microsoft account authentication with 2FA support (OAuth 2.0 device code flow)

  • Anti AFK

  • Reconnexion automatique

  • Planificateur de scripts

  • Contrôle à distance

  • Réponses automatiques

  • Attaque automatique

  • Pêche automatique

  • Manger automatiquement

  • Craft automatique

  • Mailer Bot

  • Drop automatique

  • Replay Mod

  • Une API pour créer des Bots en C#

  • Support de Docker

  • Gestion de l'inventaire

  • Book Support

  • Traversement de terrain

  • Gestion des entités

Note: Some of these features are disabled by default. You need to enable them in the configuration file, and some also require additional setup.

Remarques sur certaines fonctionnalités

Gestion de l'inventaire, du terrain et des entités

MCC currently supports Minecraft versions 1.4.6 through 26.1.

Feature support still depends on protocol version:

  • Inventory handling is supported on 1.8+.
  • Terrain handling is supported on 1.7.2+.
  • Entity handling is supported on 1.8+.

These features may lag behind brand-new Minecraft releases when Mojang changes the protocol or registries in a major way.

S'il y a eu une mise à jour majeure du jeu et que MCC n'a pas été mis à jour pour supporter les nouvelles fonctionnalités, si vous êtes développeur, vous êtes libres de contribuer au projet.

Recherche de chemins et physique

MCC now uses A* path-finding together with a physics-based movement system for movement and collision handling.

Ce qui est actuellement supporté et fonctionne :

  • Terrain navigation with A* path-finding and physics-driven movement
  • Collision-aware movement using real block shapes
  • Automatic jumping when the path requires moving up
  • Step-up movement for slabs and similar low obstacles
  • Sneaking and sprinting
  • Movement physics in water and lava
  • Climbing up and down ladders and all types of vines
  • Gravity, friction, and block speed modifiers such as ice, soul sand, soul soil, and honey blocks

Current limitations:

  • Path-finding is still block-based, so very complex terrain can still fail
  • Automatic route planning still avoids underwater routes by default, so this is not a full swimming path-finder yet
  • Knockback and other external velocity effects are not simulated yet

Avertissement

Même si tout devait fonctionner, nous ne sommes responsables d'aucun dommage que cette application pourrait causer à votre ordinateur ou à votre serveur.

Cette application ne vole pas vos mots de passe. Si vous ne lui faites pas confiance, vérifiez là & compilez directement depuis le code source.

De plus, n'oubliez pas que quand vous vous connectez à un serveur avec ce programme vous apparaitrez là où vous vous êtes déconnecté la dernière fois.

Cela signifie que ** vous pouvez mourir si vous vous connectez dans un endroit dangereux sur un serveur survie !**

Utilisez le bot de planificateur de script pour envoyer une commande de téléportation après vous être connecté.

Nous vous rappelons que vous pouvez vous faire bannir par votre serveur en utilisant ce programme. À utiliser en accord avec les règles du serveur.
