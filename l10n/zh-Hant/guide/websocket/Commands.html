WebSocket 指令

命令是透過 WebSocket 連線發送的 JSON 物件。每個命令都會透過 OnWsCommandResponse 事件。

{ "Command": "CommandName", "RequestId": "unique-id", "parameters": [[] }

協定命令

這些命令管理 WebSocket 會話本身。

Authenticate

使用配置的密碼進行身份驗證。必須在任何其他命令（ChangeSessionId 除外）之前呼叫。

參數：

附以索引型別描述
0繩密碼

範例：

{ "Command": "authenticate", "requestId": "auth-001", "parameters": ["your-password-here"] }

ChangeSessionId

重新命名目前的會話。無需身份驗證即可呼叫。新 ID 必須是 1-32 個字元，並且尚未被佔用。

參數：

附以索引型別描述
0繩新會話 ID

範例：

{ "指令": "changesessionId", "requestId": "rename-001", "parameters": ["my-bot"] }

記錄命令

LogToConsole

將訊息記錄到 MCC 控制台。

參數：

附以索引型別描述
0繩帶信息

LogDebugToConsole

將偵錯訊息記錄到 MCC 控制台（僅在偵錯模式下可見）。

參數：

附以索引型別描述
0繩帶信息

LogToConsoleTranslated

使用 MCC 翻譯鍵記錄翻譯訊息。

參數：

附以索引型別描述
0繩翻譯密鑰

LogDebugToConsoleTranslated

記錄翻譯的調試訊息。

參數：

附以索引型別描述
0繩翻譯密鑰

會話命令

ReconnectToTheServer

重新連線到 Minecraft 伺服器。

參數：

附以索引型別描述
0實事求是額外的重新連線嘗試（預設 3）
1實事求是以秒為單位延遲（預設 0）

DisconnectAndExit

斷開伺服器並關閉 MCC。沒有參數。

聊天命令

SendPrivateMessage

向玩家發送私訊。

參數：

附以索引型別描述
0繩玩家名稱
1繩帶信息

腳本命令

RunScript

執行 MCC 腳本檔案。

參數：

附以索引型別描述
0繩檔案名稱

世界和地形命令

GetTerrainEnabled

檢查是否啟用地形處理。沒有參數。返回 { "enabled": true/false }。

SetTerrainEnabled

啟用或停用地形處理。

參數：

附以索引型別描述
0濯使

GetWorld

檢查世界數據是否可用。沒有參數。如果啟用地形，則返回 { "available": true }。

DigBlock

在給定的座標處打破一個區塊。驗證該區塊在 6 個區塊內，而不是空氣。

參數：

附以索引型別描述
0倍x 座標
1倍y 座標
2倍z 座標
3繩方向（可選，例如“向下”）

Direction 參數接受字串名稱：Down、Up、North、South、West、East。

實體命令

GetEntityHandlingEnabled

檢查是否啟用實體處理。沒有參數。返回 { "enabled": true/false }。

GetEntities

取得所有被追蹤的實體。沒有參數。將實體 ID 的字典傳回實體物件。

實體類型被序列化為字串名稱（例如，"Zombie"、"Player"）。

InteractEntity

與實體互動。

參數：

附以索引型別描述
0實事求是實體 ID
1繩交互類型（Interact、Attack、InteractAt）
2繩手（可選，MainHand 或 OffHand）

SendEntityAction

發送實體操作。

參數：

附以索引型別描述
0繩動作類型（例如 StartSneaking、StopSneaking）

Sneak

切換偷偷摸摸。

參數：

附以索引型別描述
0濯真正偷偷摸摸，假停

機動命令

GetCurrentLocation

取得玩家的當前位置。沒有參數。傳回具有 x、y、z 的位置物件。

MoveToLocation

使用 Pathfinding 將播放器移至位置。

參數：

附以索引型別描述
0倍x 座標
1倍y 座標
2倍z 座標
3濯允許不安全（可選，錯誤）
4濯允許直接傳送（可選）
5實事求是最大偏移量（可選，0）
6實事求是最小偏移（可選，0）

ClientIsMoving

檢查客戶端是否正在移動。沒有參數。返回 { "moving": true/false }。

LookAtLocation

讓玩家查看座標。

參數：

附以索引型別描述
0倍x
1倍伊
2倍z

播放器資訊指令

GetUsername

取得玩家的使用者名稱沒有參數。傳回 { "使用者名稱": "..." }.

GetUserUUID

取得玩家的 UUID。沒有參數。傳回 { "uuid": "..." }.

GetGamemode

取得目前的遊戲模式。沒有參數。返回 { "gamemode": 0 }。

GetYaw

獲得玩家的偏航旋轉。沒有參數。返回 { "yaw": 0.0 }。

GetPitch

獲得球員的球場輪換。沒有參數。返回 { "pitch": 0.0 }。

GetOnlinePlayers

取得線上球員姓名列表。沒有參數。傳回一個字串陣列。

GetOnlinePlayersWithUUID

使用他們的 UUID 獲取線上播放器。沒有參數。將 UUID 字典傳回玩家名稱。

GetPlayersLatency

取得線上玩家的延遲資訊。沒有參數。

伺服器資訊指令

GetServerHost

取得伺服器主機名稱。沒有參數。返回 { "主機": "..." }.

GetServerPort

取得伺服器連接埠。沒有參數。返回 { "port": 25565 }。

GetServerTPS

取得伺服器 TPS（每秒滴答聲）。沒有參數。返回 { "tps": 20.0 }。

GetTimestamp

取得目前的時間戳記。沒有參數。傳回 { "timeStamp": "..." }.

GetProtocolVersion

取得 Minecraft 協定版本。沒有參數。返回 { "protocolVersion": 769 }。

GetMaxChatMessageLength

取得最大聊天訊息長度。沒有參數。返回 { "length": 256 }。

庫存命令

GetInventoryEnabled

檢查是否啟用庫存處理。沒有參數。返回 { "enabled": true/false }。

GetPlayerInventory

取得玩家的庫存。沒有參數。傳回帶有項目的完整庫存容器。

項目類型被序列化為字串名稱（例如，"DiamondSword"、"Stone"）。

GetInventories

取得所有開放的庫存。沒有參數。

WindowAction

執行視窗/庫存操作。

參數：

附以索引型別描述
0實事求是庫存 ID
1實事求是插槽編號
2繩動作類型（例如 LeftClick、RightClick、DropItemStack）

ChangeSlot

變更活動熱鍵槽。

參數：

附以索引型別描述
0短插槽編號 (0-8)

GetCurrentSlot

取得目前選擇的 Hotbar 插槽。沒有參數。返回 { "slot": 0 }。

SetSlot

設定活動插槽（legacy 指令）。

參數：

附以索引型別描述
0實事求是插槽號碼

ClearInventories

清除追蹤庫存狀態。沒有參數。

CloseInventory

關閉庫存視窗。

參數：

附以索引型別描述
0實事求是庫存 ID

創意模式指令

CreativeGive

在創意模式下給出一個項目。

參數：

附以索引型別描述
0實事求是插槽編號
1繩項目類型（例如 "DiamondSword" 或 798）
2實事求是伯爵

CreativeDelete

在創意模式下從插槽中刪除項目。

參數：

附以索引型別描述
0實事求是插槽編號

塊互動指令

SendPlaceBlock

放置一個塊。

參數：

附以索引型別描述
0倍x 座標
1倍y 座標
2倍z 座標
3繩方向（例如 "Up"）
4繩手（可選，"MainHand" 或 "OffHand"）

SendAnimation

玩手臂擺動動畫。

參數：

附以索引型別描述
0繩手（可選，預設 "MainHand"）

UseItemInHand

使用目前持有的物品。沒有參數。

UpdateSign

更新標誌上的文字。

參數：

附以索引型別描述
0倍x 座標
1倍y 座標
2倍z 座標
3繩第 1 行
4繩第 2 行
5繩第 3 行
6繩第 4 行

UpdateCommandBlock

更新命令區塊。

參數：

附以索引型別描述
0倍x 座標
1倍y 座標
2倍z 座標
3繩督率
4繩模式（例如 "Sequence"、"Auto"、"Redstone"）
5繩旗幟

交易命令

SelectTrade

選擇一個村民貿易。

參數：

附以索引型別描述
0實事求是交易指數

Respawn

死後重生。沒有參數。

映射命令（新）

這些指令允許客戶端在運行時動態查詢枚舉映射，因此它們不需要維護跨越 MCC 版本的硬編碼數字 ID 表。背景見 issue #2805。

GetItemTypeMappings

將所有 ItemType 名稱的字典取得到其數字 ID。沒有參數。返回 { "鑽石劍": 798, "石頭": 1, ... }.

GetEntityTypeMappings

將所有 EntityType 名稱的字典取得到其數字 ID。沒有參數。返回 { "玩家": 128, "殭屍": 119, ... }.
