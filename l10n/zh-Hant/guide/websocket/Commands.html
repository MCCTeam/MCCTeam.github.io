WebSocket 指令

命令是透過 WebSocket 連線發送的 JSON 物件。每個命令都會透過 OnWsCommandResponse 事件。

{ "Command": "CommandName", "RequestId": "unique-id", "parameters": [[] }

協定命令

這些命令管理 WebSocket 會話本身。

Authenticate

使用配置的密碼進行身份驗證。必須在任何其他命令（ChangeSessionId 除外）之前呼叫。

參數：

附以索引型別描述
0繩密碼

範例：

{ "Command": "authenticate", "requestId": "auth-001", "parameters": ["your-password-here"] }

ChangeSessionId

重新命名目前的會話。無需身份驗證即可呼叫。新 ID 必須是 1-32 個字元，並且尚未被佔用。

參數：

附以索引型別描述
0繩新會話 ID

範例：

{ "指令": "changesessionId", "requestId": "rename-001", "parameters": ["my-bot"] }

記錄命令

LogToConsole

將訊息記錄到 MCC 控制台。

參數：

附以索引型別描述
0繩帶信息

LogDebugToConsole

將偵錯訊息記錄到 MCC 控制台（僅在偵錯模式下可見）。

參數：

附以索引型別描述
0繩帶信息

LogToConsoleTranslated

使用 MCC 翻譯鍵記錄翻譯訊息。

參數：

附以索引型別描述
0繩翻譯密鑰

LogDebugToConsoleTranslated

記錄翻譯的調試訊息。

參數：

附以索引型別描述
0繩翻譯密鑰

會話命令

ReconnectToTheServer

重新連線到 Minecraft 伺服器。

參數：

附以索引型別描述
0實事求是額外的重新連線嘗試（預設 3）
1實事求是以秒為單位延遲（預設 0）

DisconnectAndExit

斷開伺服器並關閉 MCC。沒有參數。

聊天命令

SendPrivateMessage

向玩家發送私訊。

參數：

附以索引型別描述
0繩玩家名稱
1繩帶信息

腳本命令

RunScript

執行 MCC 腳本檔案。

參數：

附以索引型別描述
0繩檔案名稱

世界和地形命令

GetTerrainEnabled

檢查是否啟用地形處理。沒有參數。返回 { "enabled": true/false }。

SetTerrainEnabled

啟用或停用地形處理。

參數：

附以索引型別描述
0濯使

GetWorld

檢查世界數據是否可用。沒有參數。如果啟用地形，則返回 { "available": true }。

DigBlock

在給定的座標處打破一個區塊。驗證該區塊在 6 個區塊內，而不是空氣。

參數：

附以索引型別描述
0倍x 座標
1倍y 座標
2倍z 座標
3繩Direction (optional, e.g. "Down")

The Direction parameter accepts string names: Down, Up, North, South, West, East.

Entity Commands

GetEntityHandlingEnabled

Check if entity handling is enabled. 沒有參數。返回 { "enabled": true/false }。

GetEntities

Get all tracked entities. 沒有參數。 Returns a dictionary of entity ID to entity object.

Entity types are serialized as string names (e.g., "Zombie", "Player").

InteractEntity

Interact with an entity.

參數：

Index型別描述
0實事求是Entity ID
1繩Interaction type (Interact, Attack, InteractAt)
2繩Hand (optional, MainHand or OffHand)

SendEntityAction

Send an entity action.

參數：

Index型別描述
0繩Action type (e.g. StartSneaking, StopSneaking)

Sneak

Toggle sneaking.

參數：

Index型別描述
0濯true to sneak, false to stop

Movement Commands

GetCurrentLocation

Get the player's current location. 沒有參數。 Returns a location object with x, y, z.

MoveToLocation

Move the player to a location using pathfinding.

參數：

Index型別描述
0倍x 座標
1倍y 座標
2倍z 座標
3濯Allow unsafe (optional, false)
4濯Allow direct teleport (optional)
5實事求是Max offset (optional, 0)
6實事求是Min offset (optional, 0)

ClientIsMoving

Check if the client is currently moving. 沒有參數。 Returns { "moving": true/false }.

LookAtLocation

Make the player look at coordinates.

參數：

Index型別描述
0倍X
1倍Y
2倍Z

Player Info Commands

GetUsername

Get the player's username. 沒有參數。 Returns { "username": "..." }.

GetUserUUID

Get the player's UUID. 沒有參數。 Returns { "uuid": "..." }.

GetGamemode

Get the current gamemode. 沒有參數。 Returns { "gamemode": 0 }.

GetYaw

Get the player's yaw rotation. 沒有參數。 Returns { "yaw": 0.0 }.

GetPitch

Get the player's pitch rotation. 沒有參數。 Returns { "pitch": 0.0 }.

GetOnlinePlayers

Get a list of online player names. 沒有參數。 Returns a string array.

GetOnlinePlayersWithUUID

Get online players with their UUIDs. 沒有參數。 Returns a dictionary of UUID to player name.

GetPlayersLatency

Get latency information for online players. 沒有參數。

Server Info Commands

GetServerHost

Get the server hostname. 沒有參數。 Returns { "host": "..." }.

GetServerPort

Get the server port. 沒有參數。 Returns { "port": 25565 }.

GetServerTPS

Get the server TPS (ticks per second). 沒有參數。 Returns { "tps": 20.0 }.

GetTimestamp

Get the current timestamp. 沒有參數。 Returns { "timestamp": "..." }.

GetProtocolVersion

Get the Minecraft protocol version. 沒有參數。 Returns { "protocolVersion": 769 }.

GetMaxChatMessageLength

Get the maximum chat message length. 沒有參數。 Returns { "length": 256 }.

GetCurrentSlot

SetSlot

Set the active slot (legacy command).

參數：

Index型別描述
0實事求是Slot number

ClearInventories

Clear tracked inventory state. 沒有參數。

CloseInventory

Close an inventory window.

參數：

Index型別描述
0實事求是Inventory ID

Mapping Commands (New)

These commands let clients query enum mappings dynamically at runtime, so they do not need to maintain hardcoded numeric ID tables that break across MCC versions. For background, see issue #2805.

GetItemTypeMappings

Get a dictionary of all ItemType names to their numeric IDs. 沒有參數。 Returns { "DiamondSword": 798, "Stone": 1, ... }.

GetEntityTypeMappings

Get a dictionary of all EntityType names to their numeric IDs. 沒有參數。 Returns { "Player": 128, "Zombie": 119, ... }.
