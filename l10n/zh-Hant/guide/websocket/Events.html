WebSocket 事件

事件是推送給所有已驗證 WebSocket 客戶端的 JSON 訊息。每個事件具有以下結構：

{ "event": "EventName", "data": "{ ... serialized payload ... }" }

data 欄位是一個 JSON 字串。解析它以存取事件負載。

所有列舉值皆序列化為 字串名稱（例如 "Zombie" 而非 119）。

協定事件

OnWsCommandResponse

每個指令執行後發送。

負載：

{ "成功": true, "requestId": "your-request-id", "message": "可選結果或錯誤訊息"}

匹配 requestId 以追蹤產生此回應的命令。

OnMccCommandResponse

當純文字 mc 指令（以 /) 被執行。

負載：

{ "指令": "向北移動", "status": "完成", "result": "" }

OnGameJoined

在用戶端加入伺服器並開始遊戲會話後發送。有效載荷："N/A"

OnWsRestarting

當 WebSocket 伺服器重新啟動時（例如，在重新連線時）發送。有效載荷："N/A"

OnWsConnectionClose

當 WebSocket 伺服器關閉時發送。有效載荷："N/A"

聊天活動

OnChatRaw

發送用於每個傳入的聊天訊息，包括原始 JSON。

負載：

{ "text": "格式化文字內容", "json": "{ raw json from server }" }

OnChatPublic

偵測到公共聊天訊息時發送。

負載：

{ "寄件者": "playerName", "message": "Hello World", "RawText": "<PlayerName> 你好世界」}

OnChatPrivate

偵測到私訊時發送。

負載：

{ "寄件者": "playername", "message": "秘密訊息", "rawtext": "playername 對你耳語: secret message" }

OnTeleportRequest

偵測到傳送請求時發送。

負載：

{ "寄件者": "playername", "rawText": "PlayerName 已要求傳送給您" }

連結事件

OnDisconnect

當 MCC 斷開伺服器時發送。

負載：

{ "Reason": "ConnectionLost", "Message": "Connection 已遺失". }

原因值：ConnectionLost、UserLogout、InGameKick、LoginRejected。

實體事件

實體物件將其 type 包含為字串名稱（例如，"Zombie"、"Player"）。

OnEntitySpawn

當實體生成時發送。

有效載荷： 完整實體物件。

OnEntityDespawn

當實體消失時發送。

有效載荷： 完整實體物件。

OnEntityMove

當實體移動時發送。

payload: 具有更新位置的完整實體物件。

OnEntityAnimation

當實體播放動畫時發送。

負載：

{ "實體": { ... }, "動畫": 0 }

OnEntityHealth

當實體的健康狀況發生變化時發送。

負載：

{ "實體": { ... }, "健康": 20.0 }

OnEntityMetadata

當實體元資料更新時發送。

負載：

{ "實體": { ... }, "metadata": { "0": ..., "1": ... } }

OnEntityEquipment

當實體的設備變更時發送。

負載：

{ "實體": { ... }, "slot": 0, "item": { "type": "鑽石劍", "count": 1, ... } }

項目類型是字串名稱（例如，"DiamondSword"）。

OnEntityEffect

當實體獲得效果時發送。

負載：

{ "實體": { ... }, "effect": "speed", "amplifier": 1, "duration": 600, "flags": 0 }

OnBlockBreakAnimation

當塊中斷動畫播放時發送。

負載：

{ "entity": { ... }, "location": { "x": 10, "y": 64, "z": -20 }, "stage": 5 }

OnPlayerJoin

當播放器加入伺服器時發送。

負載：

{ "uuid": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx), "姓名": "玩家名"}

OnPlayerLeave

當玩家離開伺服器時發送。

負載：

{ "uuid": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx), "姓名": "玩家名"}

OnPlayerProperty

當播放器屬性更新時發送（例如，速度、攻擊傷害）。

有效載荷： 屬性名稱字典到值。

OnPlayerStatus

當玩家的狀態變更時發送。

負載：

{ "狀態": 0 }

OnDeath

玩家死時發送。有效載荷："N/A"

OnRespawn

當玩家重生時發送。有效載荷："N/A"

健康和體驗活動

OnHealthUpdate

當玩家的健康或食物水平發生變化時發送。

負載：

{“健康”：20.0，“食物”：20}

OnSetExperience

經驗更新時發送。

負載：

{ "ExperienceBar": 0.5, "Level": 10, "TotalExperience": 200 }

遊戲事件

OnGamemodeUpdate

當玩家的遊戲模式發生變化時發送。

負載：

{ "玩家名稱": "Steve", "uuid": "...", "gamemode": 1 }

OnLatencyUpdate

當玩家的延遲發生變化時發送。

負載：

{ "玩家名稱": "steve", "uuid": "...", "latency": 42 }

OnHeldItemChange

當保持的項目插槽變更時發送。

負載：

{ "插槽": 0 }

OnExplosion

發生爆炸時發送。

負載：

{ "位置": { "x": 10, "y": 64, "z": -20 }, "strength": 4.0, "recordcount": 12 }

OnTitle

顯示標題、副標題或動作欄訊息時發送。

負載：

{ "action": 0, "titletext": "welcome", "subtitletext": "", "actionbartext": "", "fadein": 10, "stay": 70, "fadeout": 20, “JSON”：“……”}

伺服器事件

OnServerTpsUpdate

當伺服器 TPS 更新時發送。

負載：

{“TPS”：20.0 }

OnTimeUpdate

世界時間更新時發送。

負載：

{“世界”：1000000，“時間”：6000 }

OnInternalCommand

執行 MCC 內部命令時發送。

負載：

{ "CommandName": "move", "CommandParams": "North", "Result": { "Status": "Done", "Result": "" } }

物品欄

OnInventoryUpdate

當庫存的內容發生變化時發送。

負載：

{ "InventoryId": 0 }

OnInventoryOpen

當庫存視窗打開時發送。

負載：

{ "InventoryId": 1 }

OnInventoryClose

當庫存視窗關閉時發送。

負載：

{ "InventoryId": 1 }

記分牌事件

OnScoreboardObjective

當記分板目標更新時發送。

負載：

{ "ObjectiveName": "Health", "Mode": 0, "ObjectiveValue": "Health", "Type": 0, "JSON": "...", "NumberFormat": 0 }

OnUpdateScore

當記分板分數更新時發送。

負載：

{ "EntityName": "Steve", "Action": 0, "ObjectiveName": "Health", "ObjectiveDisplayName": "Health", "Value": 20, "NumberFormat": 0 }

地圖和貿易活動

OnMapData

地圖資料更新時發送。

負載：

{ "mapid": 0, "scale": 1, "trackingposition": true, "locked": false, "icons": [], "columnsupdated": 128, "rowsupdated": 128, "mapColumnx": 0, "maprowz": 0, "colors": "base64-encoded-string" }

注意： colors 存在時是 base64 編碼的， null 否則。

OnTradeList

收到村民貿易清單時發送。

負載：

{ "Windowid": 1, "交易": [...], "VillagerInfo": { ... } }

網路事件

OnNetworkPacket

為每個網路資料包（訂閱時）發送。

負載：

{ "packetId": 42, "data": "base64-encoded-packet-data", "islogin": false, "isinbound": true }

注意：data 是 Base64 編碼的。此事件會產生大量流量，主要用於調試。
