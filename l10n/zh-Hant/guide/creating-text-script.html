建立簡單指令集

簡單的指令集是一個文字檔，每行包含一個指令。請參閱 內部指令 章節，或在主控台中輸入 /help 以查看可用指令。任何以 # 開頭的行都會被忽略並視為註解。

可以使用使用 set 指令或在 [AppVars] 設定區段中定義的應用程式變數。下列唯讀變數也可用：%username%、%login%、%serverip%、%serverport%、%datetime%、%players%（%players% 會展開為以逗號分隔的目前線上玩家名稱，若未連線則為空字串）。

範例

sample-script.txt: Send a hello message, wait 60 seconds and disconnect from server.

# This is a sample script for Minecraft Console Client
# Any line beginning with "#" is ignored and treated as a comment.

send Hello World! 我是一個使用 Minecraft 主控台客戶端編寫指令集的機器人。
wait 60 send Now quitting. Bye :) exit

請參閱 範例指令集 資料夾以取得更多範例。

如果您需要更進階的行為，請參閱 建立聊天機器人。
