關於

** Minecraft Console Client (MCC) ** 是一個輕量級、跨平台的開源 ** Minecraft ** Java 版 ** TUI ** 客戶端。它讓你無需啟動主遊戲，即可連線至 Minecraft Java 伺服器、傳送指令並接收文字訊息。

它還內建了用於管理與公用工作的自動化功能，並提供可用於建立機器人與執行階段指令集的擴充式 C# API。

它最初是由 ORelio 在2012年製作，在 Minecraft Forum 發佈。現在由他以及許多來自社群的貢獻者維護。

特色功能

  • 聊天

    • 傳送和接收聊天信息
    • 匯出聊天紀錄
    • 出現特定關鍵字時得到提醒
    • 自動回覆信息

  • 支援 2FA 的 Microsoft 帳號驗證（OAuth 2.0 裝置代碼流程）

  • 反掛機踢出（Anti AFK）

  • 自動重連（Auto Relog）

  • 腳本排程（Script Scheduler）

  • 遠端控制（Remote Control）

  • 自動回覆（Auto Respond）

  • 自動攻擊（Auto Attack）

  • 自動釣魚（Auto Fishing）

  • 自動進食（Auto Eat）

  • 自動合成（Auto Craft）

  • 郵件機器人（Mailer Bot）

  • 自動丟棄（Auto Drop）

  • 回放模組

  • 用於編寫機器人的C# API

  • 支援 Docker

  • 庫存處理

  • 書籍支援

  • 地形行走

  • 實體處理

注意：其中部分功能預設為停用狀態。你需要在設定檔中啟用它們，有些功能還需要進行額外設定。

部分功能的提示

庫存、地形及實體處理

MCC 目前支援 Minecraft 1.4.6 至 26.1 版本。

支援的功能仍取決於通訊協定版本：

  • 物品欄功能支援 1.8+ 版本。
  • 地形處理功能支援 1.7.2+ 版本。
  • 實體處理功能支援 1.8+ 版本。

當 Mojang 大幅變更通訊協定或註冊表時，這些功能可能無法立即跟上最新的 Minecraft 版本。

如果遊戲有版本更新而 MCC 又未更新至新版本，我們歡迎任何程序員為專案作出貢獻。

尋路與物理機制

MCC 現在結合 A* 尋路與基於物理的移動系統，處理移動和碰撞。

目前支援且可運作的功能：

  • 使用 A* 尋路與物理驅動移動進行地形導航
  • 依據方塊的實際形狀偵測碰撞並移動
  • 當路徑需要向上移動時自動跳躍
  • 跨上半磚及類似低矮障礙物
  • 潛行與疾跑
  • 水中與熔岩中的移動物理效果
  • 沿梯子和各類藤蔓上下攀爬
  • 重力、摩擦力，以及冰、靈魂沙、靈魂土和蜂蜜方塊等方塊造成的速度變化

目前的限制：

  • 尋路仍以方塊為單位，因此在非常複雜的地形中仍可能失敗
  • 自動路線規劃預設仍會避開水下路線，因此目前尚非完整的游泳尋路系統
  • 目前尚未模擬擊退及其他外力造成的速度變化

免責聲明

即使所有東西應該正常運作，對於此應用程序可能對你的電腦或伺服器造成的任何損害，我們概不負責。

這個程式不會偷取你的密碼。如果你不信任這個程式，請不要使用，或是請自行檢查原始碼 & 編譯。

請記得當你使用這個程式連接伺服器時，你的角色將會出現在你上次登出時的最後位置。

這表示如果你在不安全的位置登入生存伺服器，你的角色可能會死亡。

使用腳本排程（script scheduler）在登入後自動傳送傳送指令（teleport command）。

我們提醒你，你可能會因使用此程式而被你的伺服器封禁。按照伺服器的規則使用。
